# Persona interface

This records the existing app's visual system for the approved organization extension. It does not adopt the removed prototype.

## Authority

src/styles/studio.css, src/styles/governance.css, src/styles/portfolio.css, shared UI primitives and existing application screens.

## Administrative screens

Operate mode. Preserve the white/soft-green surfaces, green actions, Figtree typography, existing navigation and restrained borders. Keep one clear page title, labels next to their controls, and related settings together.

## Type and spacing

New primary form text: 1rem. Explanations: at least .9375rem. Metadata may use .875rem. Maintain readable line height and generous section separation. Use existing button and field classes.

## States

App startup and page transitions use the original centered green loading spinner, as requested. Initial reads inside the new tools show layout skeletons with a useful loading label. Known byte/job counts drive real progress. Unknown processing uses indeterminate progress. Busy forms disable duplicate submission and preserve drafts after failure. Every failed read offers retry. Reduced-motion preferences suppress animation.

## Public organization pages

Keep the existing Portfolio layout and appearance settings. Organization defaults use the full name and wording such as Welcome to, Contact our team and Chat with our AI.
